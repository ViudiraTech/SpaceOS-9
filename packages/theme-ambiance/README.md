# theme-ambiance

Declarative Ambiance theme pack for SpaceOS SPUI (`schema = 2`).

Features:
- Warm charcoal titlebars and top panel (`panel_position = "top"`, `panel_size = 28`)
- Left-side 19×19 circular amber/stone caption buttons (`button_layout = "left"`)
- Ivory window surfaces and crisp amber-orange focus/primary accents
- Radiance light chrome (`[accents.radiance]`), MATE green (`[accents.mate]`), and Ambiance Darkness (`[dark]`) variants
- Warm wave 1080p wallpaper (`/usr/share/spui/wallpapers/ambiance-wave.jpg`)
