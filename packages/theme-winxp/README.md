# Windows XP Luna SPUI Theme (`theme-winxp` 1.0.0-2)

This package provides a complete Windows XP Luna skin for SPUI 4.0 driven entirely
by SPUI's declarative CSS & SVG theme engine (`schema = 2` in `theme.toml`). It does
not contain proprietary Microsoft binaries or the copyrighted Bliss photograph; all
gradients, box-shadows, and crisp pixel-art SVGs are original/open-source CSS
recreations (`CC-BY-4.0` / MIT `XP.css`).

## Features
- **Declarative CSS + SVG Chrome (`schema = 2`)**:
  - 15-stop glossy Luna Blue titlebar with 8px top-only rounded corners and 6-layer 3D window bevels
  - 21×21 pixel-crisp SVG caption buttons (`close*.svg`, `minimize*.svg`, `maximize*.svg`, `restore*.svg`)
  - 16-stop royal-blue taskbar, curved green Start button pill (`xp-flag.svg`), and 12-stop light-blue notification tray well
  - Classic **Two-Column XP Start Menu** (`layout = "two_column"`) with glossy blue user banner, 2px orange divider, white left programs column with green "所有程序" arrow, `#d3e5fa` right system places column, and blue footer with square Logout / Reboot / Shutdown badges
  - Authentic Luna controls: warm amber hover-glow buttons, orange-highlighted tabs, chunked green progress bars, and 3-grip-line blue scrollbars
- **Built-in Color Schemes**:
  - **Luna Blue** (Default Light Mode)
  - **Olive Green / Homestead** (Select Green `#10b981` or Amber `#f59e0b` accent swatch in Settings)
  - **Metallic Silver** (Select Slate `#64748b`, Violet `#8b5cf6`, or Indigo `#6366f1` accent swatch in Settings)
  - **Royale Noir / Zune Dark** (Switch Appearance Mode to Dark `深色` in Settings)
- **Apply**:
  - Select **Windows XP Luna** directly in **System Settings → 外观与主题**, or
  - Run `spui-theme-winxp` / **Windows XP Theme** from the applications menu.
