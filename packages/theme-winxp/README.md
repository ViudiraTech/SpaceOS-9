# Windows XP Luna-inspired SPUI theme

This package is an original, XP-inspired theme for SPUI 4.0. It does not
contain Microsoft Windows assets, icons, cursors, sounds or the original
Bliss wallpaper. The wallpaper is an original SVG/JPEG gradient landscape.

- Theme id: `winxp`
- Base geometry: SPUI
- Wallpaper: `winxp-bliss.jpg` (original)
- Apply: run **Windows XP Theme** from the applications menu, or
  `spui-theme-winxp`

SPUI discovers `theme.toml` under `/usr/share/spui/themes/<id>/` and loads it
at startup based on the `theme/id` setting. No code change is needed for
additional theme packages that follow the same schema.
