# theme-aqua

Declarative Aqua Classic theme pack for SpaceOS SPUI (`schema = 2`).

Features:
- Brushed silver centered titlebars (`title_align = "center"`)
- Left-side 14×14 glossy crystal traffic-light caption buttons (`button_layout = "left"`)
- Glossy silver top panel (`panel_position = "top"`, `panel_size = 28`)
- Crystal gel pill controls and smooth progress bars (`progress_chunk_w = 0`)
- Graphite accent variant (`[accents.graphite]`) and Aqua Dark mode (`[dark]`)
- Blue wave 1080p wallpaper (`/usr/share/spui/wallpapers/aqua-wave.jpg`)
